# 無限ショートメーカー — Canvas Edition

サーバー不要の静的Webアプリ。HTML / CSS / JavaScriptのみで、Canvas映像とWeb Audioの合成音をMediaRecorderでMP4録画します。実行にNode、Python、Docker、Render、APIキー、ログインは不要です。

## ファイル

- `docs/index.html` / `docs/style.css` — iPhone向け画面
- `docs/app.js` — 1本→10本の操作、停止、未完了分の再試行、共有・保存
- `docs/engine.js` — 4ジャンル、MP4判定、映像・音声・録画
- `docs/storage.js` — IndexedDBによる端末内保存
- `docs/.nojekyll` — GitHub Pagesで静的ファイルとして配信
- `.github/workflows/pages.yml` — GitHub Actions方式を選ぶ場合の公開処理

バックエンド版は廃止しました。以前のサーバー構成はローカルGit履歴に残りますが、公開するファイルに含めません。

## 使い方

1. GitHub PagesのHTTPS URLをSafariで開きます。
2. **360×640・3秒**を選び、「まず1本を生成する」。
3. 完成した動画の「再生・保存」で再生し、「共有からファイルに保存」を押します。iPhoneの共有シートで「ファイルに保存」を選択します。
4. 同じ設定で1本の録画・MP4メタデータ読み込み・IndexedDB保存が成功すると「続けて10本」が有効になります。
5. 解像度は360 → 540 → 720 → 1080と段階的に検証します。解像度・尺・音声・字幕の設定が変わると、再び1本からの確認が必要です。

## 機能

- 物理演算：重力、壁反射、ボール同士の簡易衝突。
- ASMR風：種ごとに違う色と動きの波紋。
- ミーム：独自のシュールな宇宙人。AIモデル生成ではありません。
- 連鎖：シードごとに間隔と色の違うドミノ風アニメーション。剛体エンジンではありません。
- ジャンル選択／各動画ランダム、種ごとに異なる映像。
- 9:16、360×640 / 540×960 / 720×1280 / 1080×1920（実験的）。24fps目標。
- MP4対応を判定し、対応MIMEを順に試行。MP4非対応なら録画ボタンを無効化してエラーを表示。WebMに拡張子だけMP4を付ける処理はありません。
- BGM・効果音はWeb Audioで合成。字幕はCanvasへ描画します。マイク・カメラ権限は不要。
- 生成中の進捗、停止、未完了分の再試行。停止中の1本は破棄し、完成済みは維持。未完了リストは小さな設定データとしてlocalStorageへ保存し、再読み込み後も再試行できます（動画BlobはlocalStorageに置きません）。
- リアルタイム録画なので10本×6秒は少なくとも約60秒必要です。バックグラウンド生成はできません。Safariを前面に維持し、ロックしないでください。非表示になったら停止します。
- 録画・書き出し・IndexedDB保存は1本ずつ。ライブラリは小さなメタデータだけ読み込み、再生・共有する1本だけをBlob URLに展開します。
- 1録画24MiB、端末内保存30本・合計200MiB。上限・容量不足時は連続処理を止め、現在の1本を一時保存できるボタンを表示。
- 個別MP4ダウンロード、Web Share APIが使える場合はファイル共有。共有はファイル準備後の別タップで起動し、Safariのユーザー操作制限を考慮。
- タイトル・ハッシュタグ案、コピー、削除。

## プライバシー・費用

生成した動画をサーバーやGitHubへ送信しません。保存先は今開いているブラウザのIndexedDBです。Safariのデータ消去やOSのストレージ管理で削除され得るため、「ファイル」に保存してください。ページを他人が使用しても、その人の端末で生成します。サーバーの動画生成課金はありません。GitHub自体の契約・Pages利用条件は別です。

本アプリは認証を設けません。公開Pagesに置いたWebアプリのアクセス制限をJavaScriptのパスワードで安全に実現することはできません。APIキー等の秘密情報も使用しません。

## テストと限界

`tests/browser-results.json` と `tests/browser-test.log` に実測結果を記録します。Chromiumのモバイル幅テストはiPhone Safari実機テストではありません。

**iPhone実機のMP4録画、10本連続生成、共有シートからファイル保存、1080p動作は未検証です。「完全対応を検証済み」とは扱いません。** 端末側でMP4対応でも、メモリ、発熱、iOSの録画実装で失敗する場合があります。まず低解像度・短尺で確認してください。MP4読み込み確認は再生メタデータの確認であり、映像を最後まで人が視聴した保証ではありません。

開発時のテスト（アプリの利用には不要）：

```sh
npm test
npm run check
# Python Playwright、Chromium、FFmpegがある開発環境のみ:
python tests/test-browser.py
```

ローカル確認は開発用静的サーバー等で `docs/` を配信します。`file://` の直接オープンはES Modules・安全なコンテキストの制約により対象外です。本番はGitHub PagesのHTTPSで配信してください。

## GitHub Pages公開

具体的なiPhoneでの設定は [PAGES_SETUP.md](PAGES_SETUP.md) を参照してください。公開先は `isozin-ddd/-` を使用します。公開成功が確認できるまではURLを取得済みと表記しません。

## 権利と収益化

既存動画・既存楽曲・他者のキャラクターを同梱せず、映像と音はプログラムで生成します。ASMRはジャンル表現であり、音質・体感効果を保証しません。SNSの独自性・反復コンテンツ・収益化ポリシーを確認し、投稿前に内容を編集・確認してください。収益化を保証するアプリではありません。

停止・再読込復旧と4ジャンルの追加検証は `tests/resume-results.json` / `tests/resume-test.log` に記録しています。共有APIへのFile受け渡しはモック検証のみであり、iPhoneの共有シート確認ではありません。公開の確認状況は `DEPLOYMENT_STATUS.json` を参照してください。
