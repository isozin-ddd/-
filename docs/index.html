保存と録画のヒント

① 完成動画の「ファイルに保存」をタップ → 共有シートの「ファイルに保存」。
② 共有が使えない場合は「MP4をダウンロード」 → Safariのダウンロード一覧 → ファイルアプリ。
③ 録画が重い場合は解像度360・長さ3秒から再試行。
④ Safariを閉じた場合、途中の動画は破棄し、すでに完成した分は残します。再試行は未完了分だけを作ります。
